# Roca Fuerte Ministries and Academy

Official website for **Roca Fuerte Ministries and Academy**, located at 10501 N Mayberry Rd, Mission, TX 78573.

## 🌟 Features
- **100% Static & Lightning Fast**: Zero backend or database requirements.
- **Bilingual Interface**: Instant English ⇄ Spanish translation toggling with zero latency.
- **Direct Navigation**: Direct Google Maps and tap-to-call links for church leadership.
- **Mobile Responsive**: Optimized for phones, tablets, and desktops.

## 🚀 Deploying to Vercel

### Option A: Via GitHub (Recommended)
1. Push this repository to your GitHub account (e.g. `https://github.com/your-username/roca-fuerte-ministries`).
2. Go to [Vercel](https://vercel.com) and click **"Add New..."** > **"Project"**.
3. Select and import your **`roca-fuerte-ministries`** repository.
4. Keep the default settings (Framework Preset: *Other*) and click **Deploy**.

### Option B: Via Vercel CLI
```bash
npm i -g vercel
vercel
```
